# E-commerce-Sales-Time-Series-Analysis
21,000+ transactions (2023–2025) showed revenue was growing — but "growing" alone doesn't tell you where to invest
Cause:
Revenue-only analysis pointed to Electronics as the priority category. But growth-rate analysis told a different story: a much smaller category grew 23.7% YoY — over double Electronics' growth rate. Revenue size and growth rate were measuring two different things.
Decision:
Don't allocate marketing budget by revenue size alone — track growth rate as a separate signal for emerging opportunities.
Action (Recommended):
Increase monitoring and marketing investment in the fast-growing smaller category, without deprioritizing the core revenue driver.
Result/Value:
Recommendation only — no real marketing budget was reallocated, since this is a practice dataset.
